# 💊 تذكير العلاج — تطبيق أندرويد أصلي

نفس تطبيق «تذكير العلاج» لكن كـ **تطبيق موبايل حقيقي (APK)** مبني بـ [Capacitor](https://capacitorjs.com).
الواجهة هي نفس واجهة الـ PWA (مجلد `www/`)، والفرق الجوهري في **التنبيهات**.

## ⏰ وضع المنبّه (الافتراضي)

الجرعات تعمل كمنبّه حقيقي وليس إشعارًا عاديًا:

- يُجدول أقرب منبّه عبر `AlarmManager.setAlarmClock` (أقوى آلية في أندرويد، تتجاوز وضع السكون وتوقظ الهاتف).
- عند الموعد: **تضيء الشاشة وتظهر شاشة المنبّه فوق القفل** (اسم الدواء + الجرعة + الوقت) والنغمة والاهتزاز يعملان **بالتكرار**.
- أزرار: **✅ أخذتها**، **⏰ تأجيل**، **تخطي**، وشريط **اسحب لإيقاف الصوت**.
- إن أوقف المريض الصوت (سحب أو انتهاء المهلة 60 ثانية) دون تأكيد، **يعود المنبّه بعد مدة التكرار** (افتراضيًا كل 5 دقائق، حتى 6 مرات) إلى أن يضغط «أخذتها» أو «تخطي».
- ضغطة «أخذتها» من شاشة المنبّه تُسجَّل في التطبيق حتى لو كان مغلقًا.
- تُستعاد المنبّهات بعد إعادة تشغيل الهاتف أو تغيير الوقت.
- الإعدادات ← «ضمان وصول التنبيهات»: تشغيل/إيقاف وضع المنبّه، مدة التكرار وعدده، وإذن «الإشعارات بملء الشاشة».
- زر «اختبار إشعار» يشغّل منبّهًا تجريبيًا بعد 5 ثوانٍ: اقفل الشاشة وانتظر.

### 🔍 فحص التنبيهات + منبّه الساعة الأصلي
- الإعدادات ← «ضمان وصول التنبيهات» ← **فحص التنبيهات**: يعرض حالة كل صلاحية (إشعارات، منبّهات دقيقة، البطارية، العرض فوق التطبيقات، ملء الشاشة، صوت المنبّه) وأقرب منبّه، ومعه **سجل أحداث** يبيّن أين يتعطل التنبيه (لم يصل المنبّه؟ لم يشتغل الصوت؟ لم تفتح الشاشة؟). زر «مشاركة التقرير» لإرساله.
- **إضافة الأدوية إلى منبّه الساعة**: يضيف مواعيد الأدوية كمنبّهات يومية في تطبيق الساعة الأصلي بالهاتف، وهذا يمنحها نفس صلاحيات وموثوقية منبّه النظام نفسه. لا يمكن حذفها من التطبيق لاحقًا (احذفها من تطبيق الساعة)، ولا يعرف التطبيق هل أُخذت الجرعة.

الملفات الأصلية: `android/app/src/main/java/com/treatmentreminder/app/` (`AlarmService` و`AlarmActivity` و`AlarmReceiver` و`AlarmStore`).

## ما الذي تغيّر عن نسخة الـ PWA؟

| | PWA (متصفح) | هذا التطبيق (أصلي) |
|---|---|---|
| التنبيه بعد إغلاق التطبيق | غير مضمون | ✅ مجدول في نظام أندرويد نفسه (AlarmManager) |
| التنبيه والهاتف في وضع السكون (Doze) | غير مضمون | ✅ `allowWhileIdle` |
| بعد إعادة تشغيل الهاتف | يضيع | ✅ تُستعاد التنبيهات تلقائيًا |
| زرّا «أخذتها» / «تأجيل» داخل الإشعار | عبر Service Worker | ✅ أزرار إشعار أصلية |
| النغمات | داخل الصفحة فقط | ✅ النغمات السبع المدمجة **و نغمات الهاتف الأصلية** (إشعارات/منبّهات/رنات) عبر منتقي النظام |
| الاهتزاز | أندرويد فقط عبر المتصفح | ✅ نفس نمط الاهتزاز المختار (خفيف/مزدوج/نبض/قوي) على قناة الإشعار |
| ضبط الصلاحيات | يدوي | ✅ التطبيق يطلب بنفسه: الإشعارات، المنبّهات الدقيقة، واستثناء البطارية، ويعرض نصيحة حسب شركة الهاتف |
| تصدير النسخة الاحتياطية / التقويم | تنزيل ملف | ✅ نافذة «مشاركة» (حفظ في Drive، إرسال بواتساب، فتح في التقويم…) |
| زر الرجوع في أندرويد | — | ✅ يغلق النافذة ← يرجع لـ«اليوم» ← يخرج |

**كيف يعمل الجدولة؟** عند كل تغيير (إضافة دواء، تسجيل جرعة، تعديل إعداد…) وعند فتح التطبيق، يُلغي التطبيق التنبيهات القديمة
ويجدول **الـ 14 يومًا القادمة** كاملة (حتى 300 تنبيه). ملاحظة: إن لم تفتح التطبيق إطلاقًا لأكثر من 14 يومًا ستنتهي التنبيهات المجدولة،
فافتحه مرة كل أسبوعين على الأقل.

## 🚀 أسهل طريقة للحصول على ملف APK (بدون تثبيت أي شيء على جهازك)

1. أنشئ مستودعًا جديدًا على [GitHub](https://github.com/new) وارفع إليه محتويات هذا المجلد كما هي.
2. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow** (يعمل تلقائيًا أيضًا عند كل push).
3. بعد ~5 دقائق افتح التشغيل الناجح ونزّل **treatment-reminder-apk** من قسم Artifacts، ثم فك الضغط لتجد `app-debug.apk`.
4. انقل الملف للهاتف وافتحه (فعّل «السماح بالتثبيت من هذا المصدر» عند الطلب).

## 🛠️ البناء على جهازك

المتطلبات: Node 22+ ، JDK 21 ، Android Studio (أو Android SDK).

```bash
npm install
npx cap sync android
npx cap open android        # يفتح Android Studio ← Run ▶ على هاتفك أو المحاكي
# أو من سطر الأوامر:
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

بعد أي تعديل في ملفات `www/` شغّل `npx cap sync android` ثم أعد البناء.

## ✅ أول تشغيل على الهاتف

1. وافق على إذن **الإشعارات** (أندرويد 13+).
2. وافق على إذن **«المنبّهات والتذكيرات»** (أندرويد 12+) — بدونه قد يتأخر التنبيه بضع دقائق. التطبيق يطلبه ويُظهر تنبيهًا في الإعدادات إن كان ناقصًا.
3. اضغط **اختبار إشعار** من الإعدادات ← يصلك إشعار بالنغمة المختارة بعد ثانية ونصف.
4. بعض الشركات (Xiaomi / Huawei / Oppo / Vivo / Samsung) توقف التطبيقات في الخلفية بقوة: من إعدادات الهاتف
   ← التطبيقات ← تذكير العلاج ← البطارية ← اختر **«بدون قيود»**، وفعّل «التشغيل التلقائي» إن وُجد.

## 📦 النشر على Google Play (لاحقًا)

```bash
keytool -genkeypair -v -keystore my-release.keystore -alias release -keyalg RSA -keysize 2048 -validity 10000
```
أضف إعداد `signingConfigs` في `android/app/build.gradle` ثم `npm run aab`. **احتفظ بملف الـ keystore وكلمة سره** — بدونهما لا يمكنك تحديث التطبيق.
صلاحية `SCHEDULE_EXACT_ALARM` تتطلب تصريحًا في Play Console لتطبيقات التذكير الدوائي.

## 🧪 الاختبار

```bash
cd www && python3 -m http.server 8777 &
python3 tests/test_native.py     # يحاكي Capacitor داخل Chromium ويتحقق من الجدولة والإجراءات
```
يتحقق من: جدولة 14 يومًا، «أخذتها» تُزيل التنبيه، «تأجيل» يضيف تنبيهًا بعد المدة، تغيير النغمة يبدّل القناة، إيقاف الإشعارات يلغي كل شيء، زر الرجوع.

## ⚠️ حدود معروفة

- شدّة الصوت في الإشعار الأصلي تتبع مستوى صوت **المنبّه** في الهاتف (القناة بنوع «منبّه» لضمان الإسماع).
- بعد تغيير النغمة أو نمط الاهتزاز يُنشأ للتطبيق قناة إشعار جديدة باسم النغمة (طبيعة أندرويد)، وقد ترى عدة قنوات في إعدادات الإشعارات.
- التطبيق **ليس جهازًا طبيًا** ولا يغني عن استشارة الطبيب أو الصيدلي.
